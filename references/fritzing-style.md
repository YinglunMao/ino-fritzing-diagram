# Fritzing Parts 风格规范

本文件是 `parts_library.py` / `fritzing_kit.py` 的**美学契约**。写新 `render_*()` 前先读它，
避免画出一堆「看起来像示意图但不像 Fritzing」的东西。

Fritzing 的 breadboard view 之所以一眼可辨，靠的不是精细建模，而是**四件事的克制**：
正投影、平涂、深色描边、白色丝印。

---

## 1. 视角：正交俯视（Orthographic Top-Down）

- **只用 90° 俯视**，不画透视、不画斜角、不画侧壁厚度。
- 需要表达高度差时用**同色系略深的色块叠在下方**（如 USB-C 座、排针塑料块），
  而不是画立体侧壁。厚度感靠「描边 + 一层深色底」两笔完成。
- 元件一律正面朝上摆放，**元件之间不互相遮挡**。

## 2. 颜色：平涂，无渐变

- **禁止 `linearGradient` / `radialGradient` / `filter: drop-shadow`**。
- 每个形状一个纯色 `fill`，靠 `stroke` 区分边界。
- 同一元件最多用 **4 个色阶**：PCB 主色、丝印白、金属/触点、深色塑料。

标准 PCB 配色（对应 `fritzing_kit.C`）：

| 用途 | 名称 | 色值 |
|------|------|------|
| 通用蓝 PCB | `pcb_blue` | `#1565C0` |
| 深蓝（AS7341 类） | `pcb_blue_dk` | `#0D47A1` |
| 绿色 PCB | `pcb_green` | `#2E7D32` |
| 黑色 PCB | `pcb_black` | `#212121` |
| 红色 PCB | `pcb_red` | `#C62828` |
| 紫色 PCB | `pcb_purple` | `#6A1B9A` |
| 深海军蓝（FC-04 类） | `pcb_navy` | `#1A237E` |
| 丝印 | `silk` | `#FFFFFF` |
| 金属/排针 | `metal` | `#C9CDD2` |
| 金色触点 | `gold` | `#E8B84B` |
| 深色塑料/外壳 | `plastic_dk` | `#37474F` |
| 描边 | `edge` | `#263238` |
| 焊盘铜 | `copper` | `#B08D57` |

**描边规则**：所有 PCB 外框用 `edge` 描边，宽度 **0.25mm**（`stroke=0.25`，在 `Svg` 里会自动乘 `MM`）。
小器件（0805 电阻、LED）描边可细到 0.12mm。**不要用纯黑** `#000` 做描边——Fritzing 用的是偏蓝的深灰。

## 3. 丝印：白色、无衬线、字号克制

- 丝印文字一律 `fill=silk`（白），字体 `font-family="Helvetica, Arial, sans-serif"`。
- 引脚名（`VCC/GND/SDA/SCL/INT`）字号 **≈1.3mm**；元件型号名（`AS7341`）**≈2.0mm**。
- 引脚名尽量贴在**各自焊盘正上方或正下方**，不要挤在元件中央。
- 文字压到深色底时用 `halo=True`（`paint-order="stroke"` 白描边）保证在蓝/黑 PCB 上也读得清——
  但白字压白丝印区时**不要**加 halo，会糊成一团。

## 4. 焊盘与排针

- 通孔焊盘：外径 **1.7mm** 的 `gold` 圆 + 内径 **0.7mm** 的 `#1A1A1A` 孔（`pad()`）。
- 2.54mm 排针：黑色塑料长条（`#1A1A1A`）+ 每针一个金色方块（`male_pins_out()`）。
- **安装孔**用白色或金色圆环 + 中心浅灰孔（`mount_hole()`），四角对称，直径 2.2mm。
- 过孔（via）小圆 0.9mm，深金 `#8D6E63`。

## 5. 各元件的外形指纹

`render_*()` 要抓住每个模块**最有辨识度的那几个特征**，其余省略：

| 元件 | 必备指纹 |
|------|---------|
| Geekble nano ESP32-S3 | 43.2×17.8mm 细长板 · 两侧各 15 针 · USB-C 在短边 · 板载 LED · 屏蔽罩 |
| MPU6050 (GY-521) | 蓝色方板 · 中央 QFN 芯片 · 8 针排针在长边 · 电位器/电容点缀 |
| AS7341 模块 | 深蓝小板 · 中央白色光谱窗口（**关键识别点**）· 6 针单排 |
| Pulse Sensor | **圆形** 15.8mm 板 · 中央白色 heart 丝印 · 顶部小凸耳 + 3 个焊盘 |
| LM2904 麦克风 (FC-04) | 深海军蓝长条 35×16mm · 左侧**圆柱形电容咪头**（`mic_can`）· 4 针 |

> 圆形板、白色光谱窗、圆柱咪头、heart 丝印——这四个是让图「一眼认得出」的锚点，优先保证。

## 6. 尺寸：以实物毫米为准

- 所有 `render_*()` **按实物尺寸绘制**，单位 mm，`Part.w/h` 就是真实外廓。
- 排针间距固定 **2.54mm**，不要为了好看压缩。
- 绘图板上的「元件大小关系」必须与实物一致——这是接线图能指导焊接的前提。
- 拿不到精确尺寸时，按照片比例估一个合理值，并在 `report.md` 里注明「尺寸为估算」。

## 7. 反例（看到就改）

| ❌ 不要 | ✅ 要 |
|---------|-------|
| `<linearGradient>` 渐变金属 | 单一 `#C9CDD2` 平涂 |
| 画成立体透视、有侧壁 | 正交俯视 + 深色底叠层 |
| 元件互相压盖 | 分开摆放，图上明确留白 |
| PCB 用纯黑描边 | `#263238` 深蓝灰描边 |
| 字号过大顶出板外 | 型号 2.0mm / 引脚 1.3mm |
| 引脚名堆在芯片中央 | 贴各自焊盘 |
| 忘记白色光谱窗/heart 丝印 | 补上识别锚点 |

---

## 自检口诀

> **俯视 · 平涂 · 灰描边 · 白丝印 · 毫米真尺寸 · 一个识别锚点**

画完用 `cdp.mjs shot` 光栅化，退到 50% 缩放看一眼：
如果缩小后还能认出「这是 AS7341 还是 MPU6050」，风格就对了。
